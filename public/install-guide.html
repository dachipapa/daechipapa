홈 화면에 추가하면 앱처럼

앱스토어 설치 없이, 아이콘 하나로. 1분이면 끝나요.

카톡·카페 링크로 열었다면 먼저 브라우저로 여세요. 카카오톡·네이버 카페의 내장 화면에선 "홈 화면에 추가"가 안 나와요. 우측 상단 ⋯ 메뉴 → "다른 브라우저로 열기"(Safari/Chrome)를 먼저 눌러주세요.
iPhone Safari에서
1
하단(또는 상단)의 공유 버튼을 누르세요.
2
메뉴를 내려 "홈 화면에 추가"를 누르세요.
3
우측 상단 "추가"를 누르면 끝! 홈 화면에 대치파파 아이콘이 생겨요.
Android Chrome에서
1
우측 상단 ⋮ 메뉴를 누르세요.
2
"홈 화면에 추가" 또는 "앱 설치"를 누르세요. (설치 배너가 자동으로 뜨기도 해요.)
3
"추가/설치"를 누르면 끝! 앱 서랍·홈 화면에 아이콘이 생겨요.
설치는 선택이에요. 안 깔아도 브라우저에서 바로 쓸 수 있어요. 자주 쓸 것 같으면 홈 화면에 두는 게 편할 뿐이에요.
